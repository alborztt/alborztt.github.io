راهنمای بارگذاری نسخه جدید سایت هیأت تنیس روی میز استان البرز

محتویات:
- index.html : صفحه اصلی جدید
- assets/alborztt-logo.png : عین تصویر لوگوی ارسالی شما، بدون تغییر
- assets/table-tennis-mascot.mp4 : ویدئوی کاراکتر ارسالی شما

روش بارگذاری در مخزن alborztt/alborztt.github.io:
1) فایل ZIP را استخراج کنید.
2) وارد مخزن GitHub شوید.
3) Add file > Upload files را انتخاب کنید.
4) خود فایل index.html و پوشه assets را با هم بارگذاری کنید.
5) اگر GitHub پرسید فایل index.html موجود است، گزینه جایگزینی را تأیید کنید.
6) Commit changes را بزنید.
7) چند دقیقه بعد https://alborztt.github.io را باز و بررسی کنید.

نکته مهم:
این نسخه، طراحی ظاهری صفحه اصلی است. پنل مدیریت امن، ورود کاربران، ذخیره خبرها در پایگاه داده و سطح دسترسی مدیران هنوز در آن پیاده‌سازی نشده است. تا زمان تکمیل احراز هویت و پایگاه داده، فایل admin.html را به عنوان پنل امن در اختیار کسی قرار ندهید.
